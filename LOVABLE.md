# Sahayak AI (सहायक AI) — Lovable.dev Integration Guide

This repository (`Satvik2Sharma/AccessIt`) is fully compatible with **Lovable.dev**.

---

## 🚀 How to Import into Lovable.dev

1. Open [**Lovable.dev**](https://lovable.dev) and log in.
2. Click **Import from GitHub** or **New Project from Repository**.
3. Select this repository: `Satvik2Sharma/AccessIt`.
4. Point the root folder to `frontend/` (Vite + React 19 + TypeScript + Tailwind CSS v4).

---

## 📱 Component Sitemap for Lovable AI

All screens are located under `frontend/src/components/screens/`:

- **HomeScreen.tsx**: Central voice copilot mic button, capability cards, quick prompt pills.
- **CompleteFormScreen.tsx**: 7-step linearized scholarship form, voice dictation, confetti celebration.
- **ReadDocumentScreen.tsx**: Notice OCR comprehend, Hindi/English legal simplification, deadline badges.
- **SignTalkScreen.tsx**: ISL sign interpreter, MediaPipe 21-landmark 3D hand SVG, live webcam toggle.
- **SeeScreen**: Spatial object finder, YOLO bounding box reticle, directional haptics.
- **HeatmapScreen.tsx**: Stage 7 learning telemetry, RED/YELLOW/GREEN friction heatmap.
- **ProfileScreen.tsx**: Accessibility Twin preferences, WCAG AAA high contrast, large text mode.

- **Primary Color**: Blue (`#2563eb`), Indigo (`#4f46e5`)
